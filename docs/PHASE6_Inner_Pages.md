## 4. 技術說明

**新增樣式（site.css，只使用 tokens）**

| 元件 | 用途 |
|---|---|
| 頁首區 | 淺灰底，放麵包屑和 H1 |
| 麵包屑 | 首頁以外的所有頁面 |
| 本頁段落膠囊連結 | 服務頁、Trixo 頁的頁內跳轉 |
| 左右分欄 | 桌機左 4 欄放標題、右 8 欄放內容；手機改成單欄 |
| 公司資料定義清單 | 關於我們的公司簡介 |
| 產品區塊 | Trixo 各品項：桌機圖文左右並排、手機上下排列 |
| 品牌區塊 | 代理產品總覽的 B'BRAUN 說明 |
| 警語框 | IDPN 頁 |
| 文章排版 | 新聞內頁，最大寬 760px |
| 404 | 錯誤頁版面 |

- **404 頁**用 `<base href="/PFO-v2/">`，所以不管伺服器在哪一層路徑回傳它，連結都正確。**Cutover 時要依正式路徑修改這一行**（列入 Phase 11 QA 清單）。
- **地圖**：用 Google 地圖搜尋連結，另開新視窗，並附上給螢幕報讀器的隱藏說明文字。不嵌入 iframe（效能與隱私考量）。
- **頁面產生器 `tools/gen_pages.py`**（[PROPOSED]）：
  - 用途：10 頁共用的 Header 和 Footer 由這支 Python 腳本產生，確保每頁完全一致。只用 Python 3 標準函式庫，不需安裝任何套件。
  - 使用方式：`python tools/gen_pages.py` 會重新產生 `PFO-v2/*.html`。
  - 驗證：重新產生的結果與目前交付的 HTML 逐檔比對完全相同。
  - 需要你決定 [NEEDS CONFIRMATION]：要以這支腳本作為修改來源，還是直接手動改 HTML？**兩者擇一，不要混用**，否則腳本重跑時會蓋掉手動修改。

## 5. 修正 Phase 5 首頁的 2 個錯誤

| # | 問題 | 修正 |
|---|---|---|
| 1 | 手機選單按鈕同時顯示 ☰ 和 × 兩個圖示。原因：SVG 元素的 `hidden` 屬性不會被瀏覽器預設隱藏，而且 `.hidden = true` 對 SVG 無效 | site.css 加上 `[hidden]{display:none !important}`；main.js 改用 `toggleAttribute('hidden')` |
| 2 | 手機選單展開時蓋住 Header，看不到關閉按鈕。原因：測試橫幅把 Header 往下推，但選單的位置寫死在距頂端 64px | main.js 在打開選單時，把選單定位到 Header 實際的底邊下方 |

這兩個錯誤在 Phase 5 驗證時沒有發現：當時只檢查了選單的開關狀態，沒有看展開後的畫面。這次補上了截圖檢查。
