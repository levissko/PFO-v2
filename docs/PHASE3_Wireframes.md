## 2. 標註規則

| 標註 | 意義 |
|---|---|
| 灰標籤 `SOURCE` | 舊站原文或官方登記資料，照原文使用 |
| 藍標籤 `PROPOSED` | 架構或文案建議（按鈕文字、據點名稱、404 文案等），待 Owner Review |
| 紅標籤 `NEEDS CONFIRMATION` | 待業主確認，附 H 編號 |
| 斜線灰框 | 佔位：未授權圖片或缺少的內容。正式版不會出現佔位文字；沒有內容的區塊不顯示 |

## 3. 依指示處理的項目

**透析通路（H7）**
- 首頁服務卡片與服務頁 `#dialysis`：保留標題和舊站那一句經銷事實，加上灰階佔位框「透析通路服務說明：內容待業主提供」。
- 佔位框裡註明：舊站這一段唯一的內容是彩新數據，已排除；如果業主無法提供內容，有兩個方案：(a) 保留標題加那一句，(b) 移除這一段。

**未授權圖片（G2–G5）**：全部改成灰階佔位框，並註明原因。

| 位置 | 佔位原因 |
|---|---|
| 首頁 Hero | 沒有已授權照片（G2、G3）；在取得照片前改用純色或幾何圖形 |
| 產品圖 | 舊站圖只有約 110–150px，需要高解析圖（G5） |
| IDPN 卡片 | 依 H11，不使用原廠產品圖 |
| 新聞圖 | 舊站 news_0521.jpg 只有 190×171，解析度低 |

**其他沿用的決策**
- 全站沒有彩新連結、沒有統計數字、沒有英文公司名稱。
- Footer 不放統編、代表人、資本額。
- 地址照官方登記寫「3樓」。
- 2018 那則消息只顯示日期與摘要，不放連結。

## 4. 線框中的設計決策 [PROPOSED]

- **桌機 Header**：Logo、4 個文字選單，「聯絡我們」做成實心按鈕，不用下拉選單。
- **行動版 Header**：Logo、電話按鈕、漢堡選單。選單展開後列出 5 個項目和三據點電話；展開時鎖定頁面捲動，按 Esc 可關閉，焦點留在選單內。
- **內頁**：灰底頁首區，依序放麵包屑和 H1。長頁面（服務、產品）在頁首下方加「本頁段落」膠囊連結。
- **服務頁**：桌機用 12 欄格線，左 4 欄放標題、右 8 欄放內容；手機改成單欄。
- **產品頁**：3 個品項一律照「圖、中文品名、英文品名、產品特點、產品規格」的順序排列；桌機圖文左右並排，手機改上下排列。
- **新聞內頁**：內文最大寬 760px 以方便閱讀；舊站的粗體小標改成 H2，只修正標題階層，文字不改寫。
- **可用性**：觸控目標 ≥ 44px；電話做成可撥打連結、Email 做成 mailto 連結；每頁只有一個 H1。

## 5. RWD 規則 [PROPOSED]

| 寬度 | 行為 |
|---|---|
| 1920／1440／1280 | 內容最大寬 1200px 置中，桌機導覽 |
| 1024 | 桌機導覽，縮小側邊距 |
| 768 | 漢堡選單；卡片 2 欄；產品圖文改上下排列 |
| 430／390／375 | 單欄；按鈕全寬；觸控目標 ≥ 44px |

只畫了 1440 和 390 兩個代表寬度，其餘寬度在 Phase 7 驗證。
